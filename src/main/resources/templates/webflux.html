Módulo WebFlux

Mono, streaming con SSE y consumo de servicios con WebClient

Cada tarjeta llama a una ruta de /api/v1/reactive y muestra la respuesta. El CRUD y la API REST siguen funcionando igual que antes.

1. Mono: bienvenida al usuario

GET /api/v1/reactive/bienvenida/{usuario}
Devuelve un único resultado con el rol y la cantidad de reservas del usuario.

Pruebe con un nombre o correo registrado (carlos, maria, ana) o con uno que no exista.

    2. Flux + SSE: monitor de reservas

    GET /api/v1/reactive/reservas/stream (text/event-stream)
    Cada evento aparece apenas el servidor lo emite, uno por uno.

      3. WebClient: consulta de aulas

      GET /api/v1/reactive/aulas/consulta?fuente=...
      El servidor consulta otra ruta HTTP con WebClient (timeout de 2 s). Si falla, responde con datos de respaldo.
